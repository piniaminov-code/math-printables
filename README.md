# חשבון לכיתה ה׳

אתר משפחתי לתרגול שברים, מלבנים וסוגי ישרים בכיתה ה׳, מותאם לטלפון ובעברית מימין לשמאל.

- **תרגול**: שישה נושאים, 8 שאלות בכל סבב, עם משוב והסבר וכוכבים שנשמרים בדפדפן.
- **משחקים**: פיצה של שברים, גדול/קטן/שווה, בונים מלבן.
- **דפים להדפסה**: מבחן אקראי מכל הנושאים או דף עבודה ממוקד בנושא אחד (10 שאלות ושאלת אתגר), ברמה קלה, רגילה או מאתגרת, רגיל או פתוח, עם דף תשובות נפרד. מודפס על A4 או מורד כ־PDF.
- **ספריית דפי עבודה** (`#/library`): 22 סוגי דפים בשלוש רמות ובשלושה אורכים — שברים שקולים, השוואה וחיבור/חיסור במכנים שונים, כפל שבר במספר, שברים עשרוניים, מספרים גדולים, סימני התחלקות, כפל וחילוק במאונך וחילוק ארוך, סדר פעולות, זוויות ומשולשים, שטח של צורות מורכבות וחזרות מעורבות. סוגי שאלות: השלמה, בחירה, נכון/לא נכון, התאמה, טבלה, סידור, במאונך, ציור. לכל דף יש קוד, והקישור מחזיר בדיוק את אותו דף — אפשר לשלוח להורים אחרים.

## למתחזקים

- הספרייה כתובה כקוד קריא ב־`src/library.js` ו־`src/library.css`. אחרי שינוי בהם מריצים `node tools/build.mjs`, שמזריק אותם לתוך `index.html` (בין סמנים, אפשר להריץ שוב ושוב).

- `index.html` הוא קובץ מקומפל אחד (React + Vite + Tailwind, ‏jsPDF ו־html2canvas בפנים). אין במאגר קוד מקור ואין צורך בבנייה: האתר מוגש כמו שהוא דרך GitHub Pages.
- בדיקת מפתחות התשובות: `node tools/check-answers.mjs` (רק Node 18 ומעלה, בלי חבילות). הסקריפט מחלץ את מחוללי השאלות מתוך `index.html`, מייצר עשרות אלפי שאלות ומחשב מחדש כל תשובה ממה שהתלמיד רואה בפועל. הוא בודק גם את 39 המחוללים של הספרייה (כולל ניסוי מכוון: באגים שנשתלו נתפסו), ונכשל אם יש מפתח תשובות שגוי. כדאי להריץ אחרי כל העלאה של `index.html` חדש.
- בחירת לשון הפנייה (זכר/נקבה) נשמרת בדפדפן תחת המפתח `math-printables:gender`, וההתקדמות תחת `parents-math-practice:v1`.
